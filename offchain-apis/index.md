We provide RESTful APIs to our partners for easier integration. Here you'll find the full reference for each of our APIs, plus integration guides.

# Documents

* [Introduction](introduction.md) - We provide RESTful APIs to our partners for easier integration.
* [Callback notifications](notification-webhooks.md) - These callbacks are made from Ensuro's system back to partner's systems to notify about events on policies. It's mainly used for asynchronous policy creation/resolution/cancellation/replacement
* [Pricing API](pricing-api.md) - This API is used for policy pricing, creation, resolution, replacement and cancellation.
* [Offchain API](offchain-api.md) - REST API to query information about policies and other components of the protocol.
